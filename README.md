# HDL implementation of Simplified SD Physical Layer

## Directory structure
- dv - Design Verification files
  * sim - Simulation files
- rtl - RTL files (Verilog)

## Required software
- Design Verification
  * Simulation
    + [cocotb](https://github.com/cocotb/cocotb)
    + [pytest](https://docs.pytest.org/en/9.0.x/)
    + [Icarus Verilog](https://github.com/steveicarus/iverilog)
    + [GTKWave](https://github.com/gtkwave/gtkwave) (displays the .vcd waveforms generated by Icarus Verilog)
